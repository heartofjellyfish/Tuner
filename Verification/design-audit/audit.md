# 逐页设计检查

检查依据：当前原生模拟器全页截图、琴头参考图，以及调音页的待机、输入、调准和完成状态。判断依次关注乐器辨识度、结构正确性、轮廓连接、线条密度、反馈是否落在对应弦上、标签与点击目标的关系。

| 页面 | 发现的问题 | 本次调整 |
| --- | --- | --- |
| Guitar | 琴头肩部突然折入琴颈；引线穿过弦钮和轴柱，形成十字；弦钮与轴柱反馈不一致。 | 肩部使用连续曲线；引线停在外侧弦钮之前；弦钮与对应弦一起变色。保留 3+3 布局与粗细顺序。 |
| Ukulele | 琴头直接沿用吉他的高度，2+2 弦钮之间空白过大，看起来过长。 | 使用独立的 340 高度画板和更紧凑的弦钮间距，仍按固定比例绘制；肩部与引线一起修顺。 |
| Bass | 斜排轮廓已比之前清楚，但右侧引线仍穿入琴头，弦钮保持白色而弦变绿。 | 引线缩短到琴头外侧；对应的大弦钮一起变色。保留单侧四弦与五、六弦的双侧布局。 |
| Violin | 卷轴被简化成两个大面，容易看成球形零件；卷轴顶部有尖接点；琴箱入口由两条直观上不连贯的边线构成。 | 改为一条清楚的卷曲转折，轮廓顶部连续；填色面沿同一结构曲线；琴箱入口使用柔和曲线。保留四个侧向琴轴和短指板。 |
| Viola | 与 violin 相同的曲线问题。仅靠琴头造型很难可靠地区分两者。 | 使用同一组自然轮廓，保留较宽比例、正确 CGDA 音名和清楚的页面名称；避免为区分而添加假结构。 |
| Cello | 与 violin 相同的曲线问题；相同结构不应该靠增加装饰线表示厚重感。 | 使用相同的干净曲线与较宽比例，保留 CGDA 的低音八度。 |
| Banjo | 第五弦在琴颈侧边，因此绿色弦长很短；对应弦钮不变色时，用户看不出调的是哪根弦。 | 第五弦钮直接变色；保留短弦从侧边开始的结构，缩短标签引线。 |
| Mandolin | 两个实物弦钮对应一组音名，但标签悬在中间，分组不明显；顶部 GDAE 与弦标签重复。 | 淡括线将两个弦钮归为一组，双弦一起高亮；首页显示简短调弦名称，完整信息留在调弦列表。 |
| Chromatic | 需要在音符交界、静音和调准时检查音名、边界及绿色反馈，不能只看一个静态截图。 | 检查现有环的静音、偏低、偏高、跨界与绿色状态；保留用户确认的音域重合方式。 |

## 设计约束

保持蓝色与细线风格、居中的大音名、短指板、固定页面，以及已有调音检测逻辑。减少重复描边和穿插线，保留乐器的结构线。待机时不给出虚假的音高或调准反馈。

## 扩展结构与完成状态

五、六弦贝斯的右侧弦钮原先未镜像，轴柄朝向不对；现已镜像，并用独立平顶轮廓与外侧标签引线。自定义五弦提琴的上方琴轴原先超出琴轴箱，现按斜向箱壁安排位置。

提琴完成状态不再在原本圆琴轴上叠加第二个圆框；班卓短第五弦也只显示勾，避免大圆挤入侧边琴钮。

- 本次为绘图、布局和反馈检查；使用测试注入音高，没有据此宣称真实麦克风检测精度提升。

## 弦钮位置与方向复查

上次截图检查遗漏了吉他顶部弦钮与琴头外缘的重叠，以及四弦贝斯弦钮轮廓与斜轴不共轴的问题。

- 吉他、尤克里里、班卓和曼陀铃：整个弦钮移到琴头外，保持内部轴柱、轴柄和外部弦钮的连接顺序。标签引线及曼陀铃分组括线随弦钮位置调整。
- 四弦贝斯：轴柄按直段琴头边缘的法线绘制；花瓣轮廓以轴柄为中心对称，并一起旋转约 12.3°。
- 五、六弦贝斯：左右弦钮镜像、水平共轴；移到琴头外侧，删除挤在弦钮与标签间的短引线。
- 提琴家族：琴轴钮原本在琴轴箱外，本次保留侧向琴轴的结构。

本轮验证：八种乐器弦点击检查通过；八种琴头与五／六弦贝斯最终截图测试通过；SE 全部 16 个待机／完成状态测试通过。已放大复查吉他、尤克里里、贝斯、班卓、曼陀铃的弦钮与引线，最终签名构建通过并已更新到配对 iPhone。

## 提琴琴轴箱交叉线复查

参考用户局部截图，移除琴轴箱内部额外的拱形描边；它与真实弦线交叉并形成尖角。将三角侧面收为贴外缘的窄阴影，保留卷轴和外轮廓。琴轴柄的可见起点改为同一条箱壁曲线，不再从箱内穿过正面与外缘。小提琴、中提琴、大提琴共用此修正，自定义弦数也沿相同箱壁连接。

截图复查后，将可见弦头接到琴轴与箱壁的同一交点，避免移除遮挡后留下悬空线头；四根弦在斜向琴枕上各自折入短指板。

提琴本轮验证：最终琴头截图、自定义五弦琴轴点击检查与 SE 全部待机／完成状态测试通过。已检查三种提琴放大截图，签名构建与手机安装成功。

## 提琴弦线与轮廓分离

上轮将弦头接到箱壁，虽然减少悬空接点，却使粗弦贴着外轮廓，看起来像多余结构边线。此次弦线恢复从箱内的真实绕弦位置直达琴枕，用很小的空心轴点交代起点；外侧琴轴柄仍按箱壁遮挡，不恢复穿过正面的横线。保留既有卷轴比例和简化后的侧面阴影。

绕弦点修正验证：原生琴头截图和自定义五弦目标检查通过；SE 待机／完成状态通过；放大复查 violin、viola、cello 后，弦线不再贴在外壁，轴点和琴枕连接清楚。真机签名构建与配对 iPhone 更新成功。

## 尤克里里的暖色花朵

琴头顶端加入一枚五瓣扶桑花线描，采用主题暖色与很淡的填色，像小型镶嵌标记。花朵位于弦钮上方，不占调音反馈区域，不新增文字、按钮或装饰动画；使用原生矢量，随琴头等比缩放。

花朵验证：原生截图测试、SE 待机／调准状态测试与 Release 签名构建通过。已更新配对 iPhone。
